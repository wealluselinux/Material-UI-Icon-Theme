# Material-UI-Icon-Theme

A clean Material Design / Material You icon pack featuring custom folders, mimetypes, actions, and Google launcher integration.

> **⚠️ NOTE:** This icon theme and its installer **only work on KDE Plasma** desktop environments.

---

## Prerequisites

Before running the installer, ensure you have `git` installed on your Linux distribution.

<details>

* **Gentoo:**
  ```bash
  sudo emerge --ask dev-vcs/git
  ```
* **Ubuntu / Debian / Linux Mint:**
  ```bash
  sudo apt update && sudo apt install git -y
  ```
* **Fedora / RHEL / CentOS:**
  ```bash
  sudo dnf install git -y
  ```
* **Arch Linux / Manjaro / EndeavourOS:**
  ```bash
  sudo pacman -S git --noconfirm
  ```
* **openSUSE:**
  ```bash
  sudo zypper install git
  ```
* **Alpine Linux:**
  ```bash
  sudo apk add git
  ```

## How To Install

### Step 1: Clone the Repository
Open your terminal and run the following command to download the theme repository to your home folder:

```bash
cd ~
git clone 
```
*(Be sure to replace `YOUR-USERNAME` with your actual GitHub username or repository link).*

### Step 2: Run the Installer Script
Navigate into the cloned directory, grant execute permissions to the installer, and run it:

```bash
git clone https://github.com/wealluselinux/Material-UI-Icon-Theme
cd ~/Material-UI-Icon-Theme
chmod +x installer.sh
./installer.sh
```

### Step 3: Apply the Theme
Once the installation script completes:

1. Open **System Settings**.
2. Navigate to **Colors & Themes** $\rightarrow$ **Icons**.
3. Select **Material UI** from the list.
4. Click **Apply**.
